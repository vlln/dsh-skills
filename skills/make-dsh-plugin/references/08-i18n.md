# 插件 i18n（dsh Web GUI）

> **本文件回答**：界面文案住哪、怎么切语言、宿主那一半怎么办、怎么自检。
> **不回答**：设置面契约（→ [07-settings-panel.md](07-settings-panel.md)）、UI 组件用法（→ [06-ui-style.md](06-ui-style.md)）。

**来源**：官方 `packages/client/locale`（`LocaleRuntime` / 用户偏好 / 语言包 / `resolveText`）、`scripts/verify-client-ui-i18n.ts`（官方门禁：译文只许住在字典文件里）、`docs/cookbook/adding-a-package.md` §5（包显示元数据）、`packages/util/package-manifest`（`LocalizedText` / `PluginLocalizedMeta`）、`packages/settings/settings`（`ctx.settings.describe()`）、官方参考实现（`ui-commands`、`ui-model-selection`、`command-compact`）。基线 **0.2.0-rc.2**（tag `dsh-v0.2.0-rc.2`）；**0.2.1-rc.1 复核**：`register`（typed 形式要求 `zh`/`en` 两套）、`addLanguage`、`bind`、`resolveText`、`getSnapshot`、设置命名空间 `locale` 的 `preference` 均成立；界面细节未逐条重核，冲突时以安装的运行时为准（见 [SKILL.md](../SKILL.md)「溯源」）。

## 0. 先分流：这段文案归谁

| 文案出现在哪 | 归属 | 做法 |
|---|---|---|
| 浏览器 UI（按钮、标签、tooltip、`aria-label`、空态、计数） | **客户端字典** | §1 `ctx.locale.register(ns, { zh, en })` |
| Plugins 页里本插件的**标题 / 描述** | **包显示元数据** | §2 `locale/en.json` + `locale/zh.json` |
| 宿主产生的用户可见文本（命令回执、工具结果、注入消息） | **Node half** | §3（官方自己留英文；要本地化有两条路） |
| 模型可见文本（tool / schema description、prompt 片段） | **不是 UI 文案** | 不进字典——翻译只会动 prompt 缓存 |

## 1. 客户端字典（主路径）

```js
export const inject = ['locale']

export function apply(ctx) {
  ctx.effect(() => ctx.locale.register('loop', { zh, en }), 'loop: dictionaries')
  // 组件经 slot 注册项的 locale 拿 t；非 slot 面用 ctx.locale.bind('loop')
  ctx.slots.inject('conversation.input.dock', () => ctx.slots.register({
    name: 'conversation.input.dock', id: 'loop', order: 15, locale: 'loop',
  }, LoopBar))
}
```

- **两种随包语言都要给**（缺一个在官方是类型错误）；语言切换即时生效，不需要重挂载。
- **键写成点分小写、至少两段**（`label.fork`、`empty.noSessions`）——官方门禁 `verify-client-ui-i18n` 正是靠这个形状把 `t('label.x')` 认作键；一段式会被当成文案。
- **译文只许住在字典文件里**：门禁只放行 `locale.ts` / `locales.ts` / `locales/` 下的字面量；展示代码里的 JSX 文本与 `label` / `title` / `placeholder` / `aria-*` 都会被拦。第三方没有这道门禁，但照同一条纪律写，升级/迁移才不返工。**手写单文件 bundle 的变体**（无构建步骤，如 `vlln/dsh-autofork`）：字典内联成模块级 `DICTS = { zh: {…}, en: {…} }`，用仓库自带门禁守"字典之外没有中文文案字面量"（见 §4）。
- **命名空间是自己的**（`'loop'`、`'settings.loop'`），别往 `common` 里塞（`common` 是宿主共享词兜底：先本 ns，再 `common`，最后显示键本身）。
- **官方控件不读 locale**：`ui-primitives` 的 `label` / `*Label` / `labels` 都要传**已本地化**字符串（见 [06-ui-style.md](06-ui-style.md) §8）。
- **`t` 每次渲染现取**：字典后注册也能被已挂载 UI 拿到；切换语言时组件重渲、`<html lang>` 同步。
- **新增语言包**（支持宿主没有的语言）：`ctx.locale.addLanguage({ id: 'ja', label: '日本語', fallback: 'en' })`——`fallback` 必须已注册且链终止于 `en`。
- **包文本映射**：`ctx.locale.resolveText(LocalizedText)` 解析 `{ en, zh }` 形状（字面量原样返回）。

## 2. 包显示元数据（Plugins 页的标题与描述）

走**文件**而不是代码：

```json
// locale/en.json
{ "meta": { "title": "Autofork", "description": "Fork the session when the agent is busy." } }
// locale/zh.json
{ "meta": { "title": "自动分叉", "description": "Agent 忙时自动分叉会话。" } }
```

- `package.json` 两处一起改，否则发布就丢：`exports` 加 `"./locale/*.json": "./locale/*.json"`，`files` 加 `"locale/*.json"`。
- **回退链**（宿主读文件、不激活插件）：标题 = `meta.title` → `package.json.name` → Cordis 插件名；描述 = `meta.description` → `package.json.description` → 无。
- 字段可缺；**存在就必须是非空字符串**，JSON 写坏只给该插件一条诊断（其余字段仍可用）。
- 图标同源：`package.json` 顶层 `icon`（见 [SKILL.md](../SKILL.md) Step 2b）。

## 3. 宿主侧（Node half）

**官方立场：宿主文案留英文。** 实例：`command-compact` 的 `description` 与回执全是英文；菜单里那句中文由**客户端**字典提供（`ui-commands` 的 `command` 命名空间）。第三方宿主命令没有官方的 `label`/`icon` 入口：宿主 `description` 可像 `vlln/dsh-loop` 那样随界面语言重注册，菜单标题则按 [06-ui-style.md](06-ui-style.md) §10.7 B 的贴面补（见 [13-gotchas.md](13-gotchas.md) 13）。

必须让宿主文案跟随界面语言时，两条路：

**A（推荐）读用户设置里的语言。** 官方把语言偏好持久化成设置命名空间 **`locale`** 的字段 **`preference`**（BCP 47）：

```js
// Node half：ctx.inject(['settings'], …) 之后
const d = ctx.settings.describe().find(x => x.ns === 'locale')
const lang = d?.value?.preference ?? d?.user?.preference   // undefined = 用户没显式选过
```

- ⚠️ **必须处理 `undefined`**：用户没选过时客户端按**浏览器**语言回退，宿主无从得知——此时用英文或插件默认语言，不要猜。
- **注册期文案**（命令描述）：语言变化后要**重新注册**才改（`commands/change` 通知会让面板刷新），或在回执文本上做（每次执行现读）。

**B 客户端回传**（`locale` 命名空间读不到时）：客户端把 `ctx.locale.getSnapshot().active` 经插件自己的 HTTP 路由回传，宿主缓存并据此选词——`vlln/dsh-loop` 的既有做法（`relayLanguage` + 状态路由上的 `?lang=`）。代价是多一份状态、多一条路由，收益是不依赖宿主设置文档的形状。

## 4. 门禁（自证：先证明它会拒，再让它守仓库）

1. **字典自洽**：zh/en 键集相等、键是点分小写（≥2 段）、值非空、**同一个键两侧的 `{占位符}` 集一致**（只在一侧写对 ⇒ 另一种语言露出 `{count}` 原文）。
2. **字典之外无硬编码文案**：扫描展示代码里的中文/全角字面量，只放行诊断串与单字符排版符号。

## 5. 改造清单（把硬编码中文搬进字典）

1. 建 `src/client/locales/zh.js` + `en.js`（或单文件 `locale.ts` 导出 `{ zh, en }`），按 UI 区域分键（`bar.*` / `dialog.*` / `empty.*` / `aria.*`）。
2. `ctx.locale.register(NS, { zh, en })`，`inject` 加 `'locale'`。
3. 组件：slot 注册项加 `locale: NS` 拿 `t`；非 slot 的模块级函数改成**接收** `t`（不要把 `t` 存进模块全局）。
4. 逐条替换硬编码：**同一句重复出现时合并成一个键**。
5. 特殊形态别硬套：
   - **拼字符串** → 改成带占位符的完整句：`t('bar.sessionLabel', { name })`；不要把可翻译的括号/量词留在代码里拼。
   - **动态状态词表**（`idle: { text: '空闲' }`）→ 键化（`state.idle`），词表只留键。
   - **来自服务端/日志的文本**（会话标题、模型输出）→ 不是你要翻的文案，保持原样。
   - **调试日志 / `data-*` / CSS 变量名 / 内部标识** → 不动。
6. 包显示元数据按 §2 加；Node 侧按 §3 决定。

## 6. 验证

- **两种语言各看一遍**：所有可见文案跟着变（可在浏览器里 Ctrl+F 找中文片段）。
- **三种语言状态**：选 `zh` / 选 `en` / **没选**（浏览器语言回退）——第三种最容易漏。
- **所有文案面**：按钮、标签、tooltip、`aria-label`、空态、错误提示、计数与量词。
- **包元数据**：Plugins 页两种语言下的标题与描述正确（含未选时的回退）。
- **宿主文案**（若走 §3）：改语言后**下一次**回执即切；缓存要失效。
- **别翻模型可见文本**：tool / schema description 保持英文。

## 7. 参考实现

| 实现 | 看什么 |
|---|---|
| `vlln/dsh-autofork` | 两层字典（客户端内联 + 宿主 `t()`）+ 语言回传 + 两处门禁的完整形状 |
| `vlln/dsh-loop` | 客户端字典 + 宿主回传（`relayLanguage` + `?lang=`） |
| 官方 `ui-commands` | 一等公民命令字典（`command` 命名空间、`label.compact`） |
| 官方 `ui-model-selection` | `ctx.inject(['commandUi', …])` 里 `register` 带本地化 `label()` / `description()` |

**autofork 的几个可抄形状**：`var DICTS = { zh, en }` + 模块级 `t`（`locale` 服务缺席时默认走内联中文，界面不会变成键名）；`ctx.locale.bind(NS)` 返回的引用**每次调用现取**当前语言；**回传优先于设置文档**（用户没选过时，浏览器已按 `navigator` 定下语言）；health 路由多下发 `lang` 字段 ⇒ 一条 `curl …?lang=en` 就能验证回传（`fr` 被忽略、`zh-CN` 取 `zh`）；**刻意不翻译**工具/schema 的 `description` 与 digest 类模型可见正文（写进门禁注释，免得后人当漏网之鱼）。

## 8. 边界与踩坑

- **可翻译文本不能用字符偏移量跨半边传**（真机才会炸的坑）：宿主在正文前拼"来自哪条会话"前缀、客户端按 `prefixLength` 切片——前缀一旦进字典，切语言后长度变了，偏移量把正文切掉一截，**静默**。正解：宿主下发纯正文（`bodyText`），偏移量只作旧消息兼容；或让渲染方自己拼前缀。**判据**：任何"另一半按长度切"的契约，只要那段文本可翻译，就是定时炸弹。
- **官方门禁只覆盖官方仓库**：`verify-client-ui-i18n` 不跑第三方，纪律靠自觉。
- **`t(key)` 缺键时返回键本身**（不是 `undefined`）：所以 `t('blocked') ?? '兜底'` 这类写法永远不会兜底，
  界面会直接显示 `blocked`。新增键必须同时补 `zh` 与 `en`（见 [13-gotchas.md](13-gotchas.md) 17）。
- **第三方宿主命令的行外观没有官方入口**（本地化 label/description 与 icon 都拿不到）——见 [13-gotchas.md](13-gotchas.md) 13。
- **`locale` 命名空间的可读性依赖条目处于 ACTIVE**：`ctx.settings.describe()` 只列活跃条目；读不到时按 §3-B 回退。
- **Desktop**：preload 提供 `getLocale()` / `onLocaleChange`，bootstrap 带 `zh_CN` / `en_US`，语言在首屏渲染前应用；`ctx.locale` 用法不变（差异见 [14-desktop.md](14-desktop.md) §5）。
